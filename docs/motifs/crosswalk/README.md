# Текстовые параллели между индексами (кандидаты без записанных связей)

Эта папка — **архив** разведочного анализа: лексическое сопоставление мотивов
(названий и описаний) между тремя индексами — Берёзкин, TMI, ATU — попарно и
вместе, с целью найти **параллельные мотивы, между которыми не указано ни одной
связи** в cross-walk. Здесь лежит код, данные и выводы этого анализа.

## Метод

Два сигнала TF-IDF в одном общем пространстве (fit на объединении трёх индексов):

- **title** — косинус по одному только названию: фильтр точности (почти
  идентичные метки);
- **doc** — косинус по «название ×3 + описание»: добавляет полноту.

Пара считается кандидатом, если сходство названий выше высокого порога **или**
сходство описаний очень высокое при мягком пороге по названию. Затем вычитаются
**все** существующие рёбра cross-walk (для ATU↔TMI — constituent / defining /
note / summary; для Берёзкин↔ATU — `atu_refs`; для Берёзкин↔TMI — `tmi_refs`).

Разбиение по уверенности: **Tier A** — ≥2 общих значимых слова в названии или
очень сильное совпадение описаний; **Tier B** — эхо по одному слову (нужен
просмотр). Как этот слой соотносится с курируемыми связями — в
[`../cross-walk.md`](../cross-walk.md) (раздел «Текстовые параллели»).

⚠️ Сопоставление **лексическое, не семантическое**: ловит текстовые параллели для
ручной проверки. Пропустит пары с иной формулировкой (синонимы, перевод), а в
Tier B есть ложные совпадения.

## Что где

| Файл | Что это |
|---|---|
| `find_parallels.py` | Автономный скрипт, воспроизводящий CSV и отчёт (оба тира). |
| `parallels_ATU_TMI.csv` | Кандидаты ATU~TMI: 602 (382 Tier A). |
| `parallels_BZ_TMI.csv` | Кандидаты Берёзкин~TMI: 2 871 (1 446 Tier A). |
| `parallels_BZ_ATU.csv` | Кандидаты Берёзкин~ATU: 29 (21 Tier A). |
| `parallels_triangles.csv` | Треугольники BZ~TMI~ATU: все три ребра параллельны, часть связей отсутствует. |
| `parallels_report.md` | Сводный отчёт: методология, счётчики, топ-30 Tier A по парам, треугольники. |

Колонки CSV: `tier`, id + название каждой стороны, `title_sim`, `doc_sim`,
`shared` (число общих значимых слов в названии). Отсортировано: сначала Tier A,
затем по убыванию score.

## Воспроизвести

```
PYTHONPATH=src python3 docs/motifs/crosswalk/find_parallels.py
```

(после `mytho motifs`, когда индексы и cross-walk собраны; нужен scikit-learn —
объявленная зависимость проекта).

## Продакшн-версия (на страницах)

Высокоуверенный тир (Tier A) вынесен в **живую подсказку на страницах мотивов**:
генератор — [`src/motifs/parallels.py`](../../../src/motifs/parallels.py), шаг
сборки `[5/5]`, пишет `outputs/motifs/parallels.json` (двусторонний список
смежности + треугольники). Сервис (`server/services/motifs.py`) отдаёт их полем
`parallels`, фронт (`page-motifs.js`) показывает разделом **«Possible parallels»**
— пунктирные чипы с бейджем сходства, явно отделённые от подтверждённых связей
cross-walk. Этот скрипт держит **оба** тира для ревью; на страницы идёт только
Tier A.
