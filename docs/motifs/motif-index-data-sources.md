# Традиционные индексы мотивов: источники данных и интеграция

*Как mythoscope собирает три традиционных индекса — Берёзкин (ареальный каталог),
Thompson Motif-Index (TMI) и Aarne–Thompson–Uther (ATU) — из машиночитаемых
источников, и как они связаны между собой. Реализация: шаг пайплайна
`mytho motifs` (`src/motifs/`). Детали данных — в
[`tmi-reference.md`](tmi-reference.md), [`atu-reference.md`](atu-reference.md),
[`berezkin-reference.md`](berezkin-reference.md),
[`tmi-bibliography-key.md`](tmi-bibliography-key.md); известные проблемы — в
[`troubleshooting.md`](troubleshooting.md).*

> Этот документ описывает систему **как она построена**. Ранее здесь лежал
> предварительный обзор-план с более осторожной оценкой (в частности, «Берёзкина
> не скрейпить»); он устарел и заменён.

## TL;DR

- **TMI** и **ATU** приходят из датасета **Trilogy** (`j-hagedorn/trilogy`,
  CC-BY-SA 4.0) — «tidy» CSV-таблицы. Ключевая — `atu_seq.csv`: она задаёт для
  каждого типа ATU **упорядоченную последовательность мотивов TMI**, и это мост
  ATU↔TMI. Сейчас: **46 238 мотивов TMI** (46 230 из Trilogy + 8 нетто из
  супплемента Mellmann), **2 247 типов ATU**.
- **Печатная классификация TMI** (division1-3 — диапазоны-заголовки вроде
  `A0–A99. Creator.`) подтягивается из **Mellmann `TMI_as_CSV`** (CC-BY-4.0) и
  джойнится на мотивы по коду/диапазону → **141 division, 138 sub-division**.
  Отдаётся в сайдбар (browse глава→division→sub-division, как у ATU) и в раздел
  **Classification** на странице мотива. Trilogy остаётся источником самих мотивов.
- **Берёзкин** скрейпится со статичного **`areasofmyths.com`** (коды мотивов,
  русские названия, определения, ареальные коды 10–74, ссылки на ATU) и
  **обогащается с `mapsofmyths.com`** (по кредам, CC BY-NC-SA 4.0): английские
  названия/определения, таксономия type/group, **прямые ссылки на TMI**, ATU-id и
  иерархия традиций (1 046 традиций). Сейчас: **3 488 мотивов**, ~3 400 с
  английским текстом и таксономией.
- **Библиография TMI** (расшифровка сокращённых цитат в `notes`) строится из
  английской библиографии **`folkmasa.org`** плюс кураторская добавка иностранных
  работ → **320 записей, 236 со ссылкой на книгу**.
- **Cross-walk** между индексами строится на шаге `[4/4]`: ATU↔TMI четырьмя видами
  (constituent из `atu_seq`, defining, и два inline — из заметок TMI и из summary
  ATU), Берёзкин↔ATU (ссылки в титулах, с починкой старых номеров), Берёзкин↔TMI
  (напрямую из кураторских Thompson-id `mapsofmyths`). Полный справочник —
  [`crosswalk.md`](crosswalk.md).

## Пайплайн и архитектура (Model B)

`mytho motifs` собирает базу в четыре шага (`src/motifs/build_motifs.py`):

```
[1/5] Berezkin  — scrape areasofmyths + обогащение mapsofmyths
[2/5] TMI       — parse Trilogy tmi.csv + библиография folkmasa
[3/5] ATU       — parse Trilogy atu_df/atu_seq/atu_combos/aft + Wikidata enrich
[4/5] Cross-walk — id-связи между тремя индексами
[5/5] Parallels — эвристические текстовые параллели (подсказки без записанных связей)
```

**Model B — только код в репозитории, не данные:**

- Сырые загрузки кэшируются в `outputs/motifs/raw/**` (**gitignored**), готовые
  индексы — в `outputs/motifs/*.json` (**gitignored**). Коммитится только код; всё
  захардкоженное (кураторская библиография, легенда ареалов, культурно-региональный
  словарь) воспроизводимо из кода.
- Обогащение mapsofmyths **под кредами** (`MAPSOFMYTHS_AUTH=user:pass` из окружения /
  `.env`). Без кредов шаг обогащения пропускается с предупреждением, и **всё
  продолжает работать**: Берёзкин остаётся с русскими названиями, без type/group,
  прямых TMI-ссылок и традиций (graceful degradation, проверено на пайплайне и
  фронте). `folkmasa`, `areasofmyths`, Trilogy — открытые, без кредов.
- Экспорт (`mytho export`) кладёт готовые `outputs/motifs/*.json`, но **не** сырые
  снапшоты `raw/**` — их волатильность отмечена в `troubleshooting.md`.

### Trilogy — ядро TMI/ATU

Из `data/` берутся **пять** файлов (`config/motifs.json → trilogy.files`):

- **`tmi.csv`** — Thompson Motif-Index: `id`, `chapter_id`/`chapter_name`,
  `motif_name`, `notes` (библиография/комментарии), `level` и `level_0…level_6`
  (разобранная иерархия). Из `notes` мы дополнительно вытаскиваем определение,
  культурные аттестации, ссылки (`†`, `Type`) — см. `tmi-reference.md`.
- **`atu_df.csv`** — типы ATU: `atu_id`, `tale_name`, `tale_type` (краткое
  содержание), научный аппарат Uther (`litvar`/`provenance`/`remarks`), `combos`.
  Из этого выводим иерархию `chapter → division → sub_division → type` (главу — из
  номера, а не из ненадёжной колонки), семьи подтипов и кликабельный summary.
  **Первоисточник — текстовая выгрузка каталога Uther 2004** (`ATU.Master.Hels.txt`,
  Helsinki), из-за чего в аппарате куча дефектов кодировки/разбиения, которые мы
  чиним (мойбейк ~94% вылечено, обрезанные скобками имена, потерянные заглавные,
  пропущенные деления). Аббревиатуры и знаменитые сборники в цитатах разворачиваем
  в тултип+ссылку. **Все детали, дефекты и решения — в
  [`atu-reference.md`](atu-reference.md).**
- **`atu_seq.csv`** — мост `atu_id → мотивы TMI` (основа cross-walk ATU↔TMI).
  Колонку `tale_variant` **не используем** (синтетические перестановки; два
  catch-all типа = ~542k из 593k строк) — держим упорядоченный уникальный набор
  мотивов на тип.
- **`atu_combos.csv`** — часто комбинируемые типы (поле «Combinations» Uther,
  с развёрнутыми диапазонами).
- **`aft.csv`** — Ashliman **Annotated Folk Tales**, 1518 текстов с `atu_id`. Берём
  **только метаданные** (лицензия текстов отдельная; индекс легче) → раздел
  «Example tales» на 182 типах.

(`propp.csv` — 33 функции Проппа-справочник, без разметки к нашим типам; `*.graphml` —
готовые сети, у нас свой cross-walk — из репозитория **не используются**, см. ниже.)

### Mellmann — классификация TMI + супплемент мотивов

`KatjaMellmann/TMI_as_CSV` (CC-BY-4.0) — независимая табличная оцифровка TMI, из
которой мы берём **только два слоя** (текстовую базу оставляем за Trilogy — она
вернее: сохраняет кинжалы `†`, лучше диакритику). Подключена как источник
`mellmann` в `config/motifs.json`, читается один раз в `trilogy.build_tmi`:

- **Печатные заголовки-классификации** (`division1-3` + `section ("tens")`) —
  диапазоны вроде `A0–A99. Creator.`, `A300–A399. Gods of the underworld.`,
  `A1810. Creation of felidae.` Их нет в Trilogy. Разбираем в 4 уровня и
  раскладываем на мотивы по вхождению кода в диапазон → **141 division / 138
  sub-division / 49 sub-sub / 1 408 section**. Питают browse-дропдаун
  (глава → division → sub_division → division3 → section, как у ATU) и раздел
  **Classification** на странице мотива.
- **Супплемент — 10 реальных мотивов**, которые Trilogy потеряла при извлечении
  (7 листьев + 3 заголовка: `C867.2, D2150, H1333.5.0.3, J2500, P100, Q323,
  T317.0.1, X751, Z356.1, Z357`). Вливаются до `_finalize_tmi`, поэтому получают
  parent/level/классификацию и попадают в cross-walk (**`X751` закрывает висячую
  ATU-ссылку**). Опечатки Mellmann чинятся на входе (`Z56.1 … detruction` →
  `Z356.1` «…from destruction…»; кривые разделители код/название). **Исключены**:
  дубль-нотация (`B172.2.2`, `M202.1[.1]`, `N591[b]` — контент уже есть как `~N`)
  и `B31` (мотив 1-го изд., выброшенный в ревизии). Итог: **46 238 мотивов TMI**.

**Обогащение ATU из Wikidata** (`atu_wikidata.py`, открытый SPARQL, best-effort):
по свойству ATU-номера **P2540** для каждого типа собираем по всем его элементам:
мультиязычные названия его *type*-элементов (`P31 = wd:Q47451145`, чтобы конкретные
сказки не выдавались за названия); ссылки на **Wikipedia** (en/ru/de/fr, пересказы);
**Wikisource-полные тексты** (любой язык — первичный текст сказки, 223 типа / 808
ссылок); и **концордансы** к другим каталогам — Grimm/**KHM**,
Аарне-Томпсон (**AaTh**), Эзоп (**Perry**/Fabulae), баллады Чайлда — из `P528`
(+ квалификатор `P972`) и свойства Perry `P1852`. Сейчас: ~481 названий, ~265
Wikipedia, ~223 Wikisource, ~328 концордансов. Сетевой сбой пропускает шаг (graceful
degradation); сырой ответ кэшируется в `raw/wikidata/`.

### Берёзкин — areasofmyths + mapsofmyths

Каталог «Тематическая классификация и ареальное распределение фольклорно-
мифологических мотивов» (Ю. Е. Берёзкин, Е. Н. Дувакин).

- **`areasofmyths.com`** — статичный фреймсет (windows-1251): `index-left.html` +
  постраничные `a*.html`. Отсюда — код мотива, русское название, короткое
  определение, ареальные коды (10–74, авторский ключ — `berezkin-reference.md §6`),
  ссылки на ATU (из титулов) и внутренние see-also (из текста определения,
  `см. мотив X`; трейлинг-коды в титуле — это Thompson-эквиваленты, идут в `tmi_refs`).
- **`mapsofmyths.com`** (сестринский сайт, те же id без учёта регистра; доступ по
  `MAPSOFMYTHS_AUTH`): `/motifs_full` — английские название и определение (мы
  **предпочитаем английский**, русский уходит в `name_rus`/`definition_rus`);
  `/node/N` — 2-уровневая таксономия type/group, прямой Thompson-id (`tmi_refs`),
  ATU-id, список традиций; `/traditions_full` — **1 046 традиций** с именованной
  4-уровневой ареальной иерархией (16→59→228→1046) и языковой семьёй.
- **`areasofmyths.com/biblio.html`** — собственная библиография каталога (~9 700
  работ, по авторам). `berezkin_bibliography.py` резолвит автор-год цитаты из
  уже-кэшированных detail-страниц в эту библиографию и **привязывает к макроареалам**
  → `berezkin_bibliography.json` (дерево `регион→цитаты` на мотив + агрегаты
  `источник→регионы`). Открытый источник, best-effort (~167k цитат, ~89% резолв).
  Привязка к этносам убрана (стоила ~120 с сборки и нигде не показывалась; шаг
  ускорился ~180→60 с). Детали — `berezkin-reference.md §6b`.

### Библиография TMI — folkmasa + кураторская добавка

`notes` в TMI цитируют источники сокращениями (`BP`, `FFC`, `Frazer`…).
`src/motifs/sources/bibliography.py` расшифровывает их: парсит английскую
библиографию с **`folkmasa.org`** и добавляет **кураторский список** иностранных
работ (в коде), почти отсутствующих у Томпсона; каждой записи проставляется живой
линк на книгу, где удалось, и число употреблений из уже разобранных `notes`.
Ключ — `tmi_bibliography.json`; человекочитаемая версия —
[`tmi-bibliography-key.md`](tmi-bibliography-key.md).

## Cross-walk (шаг `[4/4]`)

Строится в `src/motifs/crosswalk.py` из уже разобранных индексов. Всего **шесть**
отношений, каждое хранится в обе стороны; ATU↔TMI распадается на четыре
независимых вида. **Полный справочник — [`crosswalk.md`](crosswalk.md)**; ниже —
краткая сводка.

| Связь | Откуда | Ключи | Сейчас |
|---|---|---|---|
| ATU ↔ TMI — constituent | `atu_seq` (тип → его мотивы) | `atu_to_tmi` | 1 642 / 3 799 (3 765 существуют) |
| ATU ↔ TMI — defining | `defining_motifs` у метки типа | `atu_to_tmi_defining` | 62 / 74 |
| ATU ↔ TMI — note (inline) | цитаты `Type N` в заметках TMI (AaTh→ATU) | `tmi_to_atu_note` | 2 602 / 802 |
| ATU ↔ TMI — summary (inline) | коды TMI в тексте `summary` типа (диапазоны развёрнуты) | `atu_to_tmi_summary` | 1 665 / 3 810 |
| Берёзкин ↔ ATU | ссылки на ATU в титулах (`atu_refs`, alias-resolved, +чистка) | `berezkin_to_atu` | 509 / 485 |
| Берёзкин ↔ TMI (прямо) | кураторские Thompson-id из mapsofmyths (`tmi_refs`, парсим+чистим) | `berezkin_to_tmi` | 193 / 212 |

Inline-ссылки `Type N` из заметок Томпсона — номера **AaTh** (заметки старше
ATU-2004): резолвятся в прямой ATU-id, иначе через **конкорданс AaTh→ATU** из
Wikidata (`330A → ATU 330`, бейдж `AaTh 330A`), иначе — серым с тултипом. Старые
номера типов ATU чинятся через alias-карту (`former_ids`, 571 запись). Неоднозначные
и удалённые типы **не** угадываем. Механику разрешения см. `crosswalk.md §4`.

На странице мотива TMI конституентная и цитатная связи с ATU сведены в один раздел
**«Related ATU tale types»** (⇐ разложение, ⇒ заметка, ⇔ оба); defining и summary —
отдельными разделами. Прямой Берёзкин↔TMI — точная ручная конкорданс-таблица; через
ATU достижимо больше пар, но они слабее, поэтому держатся отдельно
(`berezkin-reference.md §7`).

Отдельный шаг `[5/5]` строит **эвристические текстовые параллели** (`parallels.py` →
`parallels.json`): лексические двойники мотивов **без записанной связи**, показанные
на страницах разделом «Possible parallels» как подсказки для проверки, а не
утверждённые рёбра. Метод и данные — `crosswalk.md §8` и папка `crosswalk/`.

## Overview-дашборды (общий каркас графиков)

Лендинг каждого индекса рендерит `GET /api/motifs/{index}/stats` (одна кэшируемая
свёртка) как полоску карточек-метрик и сетку графиков, разбитую на **три
цвето-кодированные секции** (`stats.sections`, поле `section` у каждой панели):

- **Geography & spread** (морская волна) — где и кем засвидетельствовано: график
  по региону и лидерборд-носитель (у Берёзкина сюда же — *Areas with the most
  motifs*).
- **Themes & content** (синий) — что индекс говорит о фольклоре: тематические
  распределения (глава, тематическая группа, дивизионы), самые распространённые и
  корреляции (cross-references), документированность.
- **Dataset diagnostics** (фиолетовый — как чипы текстовых параллелей мотива) —
  форма и полнота самого датасета: структура, гистограммы-распределения, покрытие
  полей.

Внутри каждой секции панели отсортированы **по убыванию значимости**. Все секции
следуют **общему каркасу**, чтобы параллельные виды стояли на одном месте:

> регион → лидерборд-носитель — затем глава → вторичная таксономия → самые
> распространённые → корреляции — затем диагностика датасета

Заголовки — по единой схеме: `<записи> by <категория>` (распределения),
`<носитель> per <запись>` (гистограммы охвата), `<носитель>s with the most
<записи>` и `Most widespread <записи>` (лидерборды). «Носитель» у каждого индекса
свой — **культуры** (TMI), **народы** (ATU), **ареалы** (Берёзкин), — и общий
костяк «регион → лидерборд-носитель → охват → самые распространённые» идёт подряд
и одинаково во всех трёх. Диагностический хвост индекс-специфичен: TMI —
композиция/иерархия/документация (kind, level, длина заметок, most-documented,
источники); ATU — плотность разметки (constituent-motifs-гистограмма, motif-rich);
Берёзкин — покрытие полей и длина определений. Оба индекса *мотивов* (TMI,
Берёзкин) несут лидерборд cross-referenced (в content-секции); у ATU (индекс
*типов*) его нет. Полные списки панелей каждого индекса — в
[`tmi-reference.md`](tmi-reference.md) §10, [`atu-reference.md`](atu-reference.md)
§9a и [`berezkin-reference.md`](berezkin-reference.md) §7b.

**Бины гистограмм охвата.** Распределения `<носитель> per <запись>` (cultures /
areas / traditions per motif) сильно право-скошены: масса сидит на малых
значениях, а хвост тянется на порядки величины. Поэтому все три используют
**лог-шкалу — степени двойки**: `0, 1, 2–3, 4–7, 8–15, …`, где каждый бин вдвое
шире предыдущего. На такой шкале высота столбца снова читается как масса на слое
(в отличие от неравных «ручных» бинов, где площадь перестаёт быть пропорциональна
количеству), а пик и длинный тонкий хвост видны в один взгляд (`_pow2_histogram`
в `services/motifs.py`). `0` и `1` — отдельные бины («нет носителя» / «один
носитель» — содержательные края); пустые ведущие бины обрезаются, верхний —
открытый (`512+`). Гистограммы **не**-охвата (длина заметок/определений, regions
per tale type) остаются на своих специфичных бинах — там диапазон мал и без
скоса.

## Просмотрено, но не используется

- **`fbkarsdorp/tmi`** (Apache-2.0, `tmi.json` + Whoosh) — Trilogy уже отдаёт тот
  же TMI с разобранной иерархией; полезен как сверочный источник, не подключён.
- **ATU-тезаурус TemaTres** (`vocabularyserver.com/atu`, SKOS/RDF) — канонический
  многоязычный словарь типов с линками на DBpedia; не подключён (хватает `atu_df`).
- **Missouri LibGuides**, **`propp.csv`/`*.graphml`** из Trilogy — справочник функций
  Проппа (без разметки к нашим типам) и готовые сети для задач индукции/оценки;
  к сборке трёх индексов не относятся и здесь не используются. (`aft.csv` теперь
  используется — метаданные примеров сказок, см. выше.)
- **`folkloredatabase.com`** — коммерческое зеркало; его условия запрещают
  text/data mining. Мы его **не используем** (запрет касался именно этого зеркала,
  не открытого `areasofmyths` и не лицензированного `mapsofmyths`).
