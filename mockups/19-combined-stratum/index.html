Комбинированная страта — гейтированный A × B

Один конвейер вместо двух счётчиков. Для каждого мотива: B (филогенетический сигнал на языковом дереве) решает режим — наследование (клада) vs ареал; режим выбирает инструмент датировки — глубина клады для наследуемых, географическая дизъюнкция / охват глубоких мега-сетов для ареальных. Выдаёт метку страты, глубину и confidence по согласию A и B. Тема сюда намеренно не входит — это было бы круговой логикой; она остаётся отдельной осью для независимой перекрёстной проверки.

Ключевое: «широкие» мотивы связка разводит на три режима

Метод A в одиночку назвал бы все «широкие» глубокими; метод B — все «ареальными». Связка их различает.
