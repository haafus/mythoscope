59 · Infinite-K — a Bayesian-nonparametric latent model

Mockup 47 found the admixture cross-validation curve just plateaus — no clean number of populations K. The principled answer is a model that never fixes K: a Hierarchical Dirichlet Process (traditions = documents, motifs = words), which infers an unbounded number of latent components and lets the data decide how many carry weight. We read off the effective K and — the real object of interest — the shape of the component-weight decay.
