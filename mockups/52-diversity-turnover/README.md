# 52 · Diversity turnover

Ecology's **alpha / gamma / beta** diversity split applied to motifs by macro-area (analysis #5).

- **Alpha** (mean per-tradition richness) is dominated by **cataloguing effort** — N&E Europe 365, W-Europe 260
  on top, the most-studied zones — so it is *not* a diversity signal.
- **Beta = turnover (γ/α)** is far less effort-driven and carries the real signal: **low beta = a homogeneous
  shared stock**, **high beta = internally divergent traditions**.

**Finding.** Europe is **lowest** (β 4.9–6.9) — a homogenised **diffusion belt** sharing one ATU märchen stock;
**Sub-Saharan Africa and Tibet/SE-Asia (17.1)** and the Americas are **highest** — internally divergent, each
tradition its own. The same clinal-vs-homogenised story seen from the diversity side. A world map colours each
tradition by its region's turnover (blue belt vs red divergent zones).

`build_data.py` computes α/γ/β per macro-area and the per-tradition points; writes `data.js`.
