Фасеты традиций на карте

Один и тот же набор традиций Березкина, раскрашенный по выбранному фасету. Переключай ось — карта перекрашивается. hard layers — жёсткие страты-листья рекурсивного geo-peel с поправкой на покрытие (мокап 45), volume — 14 разделов, сбалансированных по объёму фиксации Березкина (~8–10k атрибуций на раздел), area выводится из areal_path, family — из языковой цепочки, narrative — кластер традиции по её нарративному профилю (KMeans k=8 над 16-мерным профилем мокапа 41 — как в мокапе 43), subsistence — из D-PLACE (ближайшее общество ≤ 250 км), diversity — β-turnover разнообразия мотивов по макроареалу (мокап 52), depth — средний ранг глубины мотивов традиции (глубина мотива = breadth, мокап 17) с поправкой на покрытие, cosmology — доля мотивов Категории A (космогония vs приключения), peopling — возраст заселения макроареала (ky). Четыре последних — непрерывные шкалы.

Точка — традиция; где реальной координаты нет, взят центроид ареального субрегиона и точки разведены. Серые — без значения по этому фасету. Экваториальная проекция.
