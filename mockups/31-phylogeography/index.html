Филогеография — где и когда возник мотив

Capstone этиологии: для descent-мотивов, которые смог датировать мокап 30, показываем реконструкцию — место и возраст происхождения, и распространение по карте. Место = центр ареала мотива внутри его семьи (точечная оценка того, что дал бы полный relaxed-random-walk по датированному дереву). Возраст = потолок по дате экспансии семьи (мокап 30). Датируется только наследуемое меньшинство — у ареального большинства нет единого «происхождения».

Карта происхождений — точка = центр ареала descent-мотива, цвет = возраст (потолок по семье)
