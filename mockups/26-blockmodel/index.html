Degree-corrected блок-модель

Замена бикластеризации (06/07/15/23) генеративной блок-моделью матрицы мотив×традиция. Каждая традиция кластеризуется по нормированному на степень профилю над блоками мотивов (доли, сумма=1) — нормировка убирает суммарную степень, то есть объём каталога a(t). Число блоков традиций выбрано по BIC. Наивный базлайн кластеризует сырые счётчики — и, как и ожидалось, делит традиции по тому, сколько Березкин записал.

Выбор числа блоков — BIC(K_t), минимум = выбор

Degree-robustness — eta²(покрытие | блок), меньше = лучше
