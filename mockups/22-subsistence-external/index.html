Subsistence из D-PLACE + тест темы

Четвёртый фасет традиции, у которого нет источника внутри корпуса, — subsistence — берётся из D-PLACE (Ethnographic Atlas). Каждое общество D-PLACE несёт тип хозяйства (из EA042 «доминирующая активность» + EA028 «интенсивность земледелия») и координаты; традиции Березкина джойнятся к ближайшему обществу по большому кругу. Затем проверяется корреляция, которую пропозал утверждал, но не проверял: фуражиры космологичны, земледельцы сказочны (Category A против B).

Тест: доля Category A (космология/этиология) по типу хозяйства — среднее по традиции, ≥20 мотивов
