45 · Stratigraphic peeling

A coverage-corrected recursive peel of the Berezkin attestation matrix into nested layers, with each layer's geography, motif core, a breadth-based dating proxy and bootstrap stability. The structure is clinal (isolation-by-distance), so the tree is a discretisation of a continuum, not discrete strata — hence the parallel soft factors (NMF), the honest layer model. Explore both.
