53 · Implicational structure

Asymmetric co-occurrence: if a tradition has motif X it almost always has motif Y, but not the reverse → X implies Y — X is a specialization of Y. Aggregated, these recover a data-driven subtype → type hierarchy the flat motif-group can't express.

Type hubs — the motif "types" and the subtypes that imply them

Cross-theme implications — the non-obvious ones (X and Y in different theme groups)
