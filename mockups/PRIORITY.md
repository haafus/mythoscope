Full write-ups live in each mockup's own `README.md`; the complete index is [`README.md`](README.md).

## Temporal dimension & processes

| № | What it does |
|---|--------------|
| [17](17-motif-depth-score/) | Reads a motif's approximate time-depth off the shape of its areal distribution — a signal, not a calendar date. |
| [30](30-dated-phylogeny/) | Turns ordinal clade-depth into a calendar age via Glottolog + family-expansion dates (451 descent motifs dated). |
| [31](31-phylogeography/) | Maps where and when each descent motif originated and how it spread, coloured by age. |
| [49](49-chronology/) | Three routes to a time axis (datability, barrier floors, pseudo-chronology); coarse old/young polarity holds, but the main axis is geography. |
| [50](50-dated-attestations/) | Anchors motif ages to 15 dated textual corpora (Egypt ~4350 BP → Aztec ~600 BP) as lower-bound floors. |
| [55](55-ancestral-repertoires/) | Set-level ancestral-state reconstruction of proto-family mythologies (proto-IE märchen core, proto-Austronesian celestial core). |
| [57](57-contagion/) | Model-comparison of simple vs complex contagion spreading on a small-world tradition network. |

## Internal structure, semantics & thematics

| № | What it does |
|---|--------------|
| [32](32-facet-adequacy/) | Tests whether the descriptors (area / theme / family / …) each earn their place and how much they overlap. |
| [41](41-theme-rederivation/) | Checks whether the 13 hand-assigned themes match the structure the motif content itself carries (UMAP). |
| [53](53-implicational/) | Which motifs implicationally entail which — presence-of-A ⇒ presence-of-B hubs. |
| [56](56-motif-coupling/) | Separates direct motif-to-motif couplings from indirect hub-mediated correlation; finds competing variant-slots (mutual exclusion). |
| [59](59-infinite-k/) | A Bayesian-nonparametric latent model (HDP) that never fixes K, formalising "no natural number of clusters". |
