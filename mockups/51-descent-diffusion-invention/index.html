51 · Descent / Diffusion / Invention

A dispersed motif (low NRI) is not automatically deep inheritance. It can be deep descent (inherited, differentially lost → relict), late diffusion (borrowed along a contact corridor → contiguous), or independent invention (a cognitively obvious motif reinvented → simple, observational). You can't read the mode off dispersal — so this stacks the project's discriminators plus one new one, motif complexity from the definition text (a complex, arbitrary motif is not reinvented twice). A transparent heuristic, not ground truth.
