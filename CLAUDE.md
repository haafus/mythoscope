# Working rules

## Git
- Do not create branches on your own — work on `main`; only create a branch on explicit request.
- Push only to `main`.

## Code
- Keep comments minimal and only for non-obvious things: explain "why", do not duplicate what the code already shows.

## Docs
- Write paper drafts from the notes in `docs/research/` and from the mockup READMEs — not from memory.
  Those notes carry the identifiers, figures and preprint caveats that get lost in a retelling.
- Before citing a work, check author, title and venue against the primary source; mark preprints as such.
