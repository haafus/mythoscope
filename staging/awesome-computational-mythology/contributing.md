# Contributing

Thanks for helping build **Awesome Computational Mythology**! This is a curated, neutral
community list.

## What belongs here

Resources for the **computational, comparative, or quantitative** study of myth, folklore, and
traditional narrative — see the **Scope** section in the README. When in doubt, open an issue
first.

**In scope:** motif/tale-type indexes, corpora & annotated datasets, cross-cultural databases,
digital text libraries, ontologies/LOD, methods, tools, quantitative/DH studies, key papers,
venues.

**Out of scope:** general mythology retellings, single-tradition popularizations, and
non-computational reference works (unless a standard apparatus such as TMI/ATU).

## How to add an entry

1. Fork and edit `README.md`.
2. Add your entry to the most fitting section, keeping alphabetical/logical order.
3. Use the entry format:
   - Resources: `- **Name** — one-line, neutral description — [link](https://…).`
   - Papers: `- Author(s) — *Title* (venue, year).`
4. Keep it to **one line**, factual and non-promotional.
5. The resource must be **real, reachable, and not a duplicate**.
6. Open a pull request using the template; explain why it fits.

## Quality bar

- Prefer primary/authoritative sources over blog reposts.
- HTTPS links where available; no dead links (CI checks this).
- No self-promotion dressed as a resource; the list stays neutral.

## Before your PR is merged

CI runs [`awesome-lint`](https://github.com/sindresorhus/awesome-lint) and a link checker.
Please run locally first:

```sh
npx awesome-lint
```

## Reporting problems

Found a dead link, a mistake, or something out of scope? Open an issue.
